# Which Prompt I Need - Prompt Engineering Catalog

[![HTML5/JS](https://img.shields.io/badge/HTML5-Vanilla%20JS-E34F26.svg)](https://developer.mozilla.org/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

An interactive library and selector tool for categorized, high-performing prompts across major LLMs (ChatGPT, Claude, Gemini).

---

## ✨ Features

* **Curated Prompt Vault (`prompts.json`):** Categorized templates for development, copywriting, data analysis, and creative work.
* **Instant Copy & Filter:** Fast client-side search and tag filtering.
